# Tastenkürzel

Zurück zu [[00 Willkommen|Willkommen]].

## Überall

| Tasten | tut |
| --- | --- |
| `Strg+K` | suchen |
| `Alt+N` | neue Notiz |
| `Alt+T` | Tagesnotiz von heute |
| Menütaste oder `Shift+F10` | Kontextmenü am markierten Eintrag |

## Im Editor

| Tasten | tut |
| --- | --- |
| `Strg+B` | fett |
| `Strg+I` | kursiv |
| `Strg+Z` | rückgängig |
| `/` | Block einfügen |
| `[[` | Link auf eine Notiz |
| `Escape` | schließt Vorschläge und Dialoge |

## Auf der Karte

| Tasten | tut |
| --- | --- |
| Pfeile | verschieben |
| `+` und `-` | zoomen |
| `0` | alles zeigen |

Das war die Anleitung. Viel Freude mit deinen Notizen. Zurück zu [[00 Willkommen|Willkommen]].
