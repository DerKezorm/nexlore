# Shortcuts

Back to [[00 Welcome|Welcome]].

## Everywhere

| Keys | does |
| --- | --- |
| `Ctrl+K` | search |
| `Alt+N` | new note |
| `Alt+T` | today's daily note |
| Menu key or `Shift+F10` | context menu of the chosen entry |

## In the editor

| Keys | does |
| --- | --- |
| `Ctrl+B` | bold |
| `Ctrl+I` | italic |
| `Ctrl+Z` | undo |
| `/` | insert a block |
| `[[` | link to a note |
| `Escape` | closes suggestions and dialogs |

## On the map

| Keys | does |
| --- | --- |
| Arrows | move |
| `+` and `-` | zoom |
| `0` | show everything |

That was the guide. Enjoy your notes. Back to [[00 Welcome|Welcome]].
