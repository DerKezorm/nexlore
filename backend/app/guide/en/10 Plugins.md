# Plugins

Back to [[00 Welcome|Welcome]].

Plugins come from a checked catalog that ships with nexlore. The operator installs and lets them out (Settings → Server → AI and plugins); then every account switches them on for itself under **My account → Plugins for me**. Every plugin runs locked up: no network, no sign-in, only what its card lists.

## The four plugins

- **Contents:** headings, words and reading time in the right column.
- **Queries:** a `query` code block lists notes, for example all with the tag #guide:

```query
tag: guide
view: table
```

- **Kanban:** a note with columns as headings and cards as tasks becomes a board. Try it with the [[Project board]].
- **Rediscover:** a random older note, and what was written a year ago today.

While a plugin is off, you see only the code block as text here. That is on purpose: nothing runs that you did not switch on.
