# Callouts and highlights

Back to [[00 Welcome|Welcome]].

## Callouts

Callouts make something stand out. In the toolbar, choose the kind with the info symbol.

> [!note] Note
> The plainest kind.

> [!warning] Mind this
> For anything nobody should miss.

> [!tip]- Folded
> With a minus after the kind, the callout is folded when read. A click on its title opens it.

Written, it looks like this:

```markdown
> [!warning] Mind this
> For anything nobody should miss.
```

## Highlights and comments

- ==Highlighted== is text between two equals signs: `==like this==`.
- Text between two percent signs is a comment: it is in the file but does not show when read. %%You see this sentence only in the editor.%%
- Formulas go between dollar signs: $E = mc^2$.

## Tags

A word with a hash in front is a tag: #example. Tags turn up in the search and as a cloud on the map.
